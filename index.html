How to download and open it

It takes about a minute.

  1. Click Download client

    Your browser saves EclipseClient_1_19_JS.html. If nothing happens, right-click the button and choose Save link as.

  2. Find the file

    Open your Downloads folder. Keep the file in a place you will remember. Moving it later will not break it.

  3. Open it in your browser

    Double-click the file. If it opens in the wrong app, right-click, choose Open with, then Chrome, Edge or Firefox.

  4. Wait for it to load

    The first start can take a few seconds. If the screen stays black, press F5 to reload and make sure hardware acceleration is on in your browser settings.

Set up your username

Eaglercraft has no account login. Your username is just a name you choose, and you can change it any time.

  1. Open the profile screen

    On the main menu, open Multiplayer or Options and choose Edit Profile.

  2. Type your name

    Use 3 to 16 characters: letters, numbers and underscores only.

  3. Pick a skin

    Choose a default skin or upload a 64x64 PNG skin file, then press Done.

Check a name before you use it

Type a name to check it.

  • Skip spaces and symbols; many servers reject them.
  • Avoid copying staff or famous player names.
  • Pick one name and stick to it so friends can find you.

Play on servers

Eaglercraft connects through WebSocket addresses, not normal Minecraft IPs. A server must say it supports Eaglercraft 1.19 or Eaglercraft, or it will not let you in.

  1. Open Multiplayer

    From the main menu, choose Multiplayer.

  2. Add the server

    Press Add Server, type any name you like, and paste the server address.

  3. Use the right address format

    Addresses start with wss:// (secure) or ws://. If you opened the client from a website (https), use wss://.

  4. Join

    Select the server and press Join Server. You can also use Direct Connect for a one-off address.

Quick answers

 

Can't connect to a server?

Check that the address starts with wss:// or ws://, that the server supports Eaglercraft 1.19, and that it is online. Some servers only accept a certain client version.

Does it work on a phone or Chromebook?

It runs on Chromebooks and desktop browsers. Phones can open it, but touch controls are limited.

Is the game laggy?

Lower render distance in Options > Video Settings and close other tabs. Use a recent version of Chrome or Edge.

Is it the official Minecraft?

No. Eaglercraft is a community project that runs in the browser and is not made by or connected to Mojang or Microsoft.
